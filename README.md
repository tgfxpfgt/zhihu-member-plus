# 知乎盐选会员增强助手 (zhihu-member-plus)

Chrome 扩展（Manifest V3），为知乎盐选/盐智会员提供阅读增强、页面净化、效率工具与性能优化。纯本地运行，不上传任何数据。

> ⚠️ 仅服务已购会员账号，用于改善已付费内容的阅读体验，不破解任何付费内容。

## 功能总览

### 📖 阅读增强
- 沉浸式阅读 / 夜间模式 / 全屏阅读
- 字体、字号、行距、背景色自定义；10 套美化主题（微信读书风、简书风、OLED 纯黑等）
- 🎧 **听书模式（A2）**：逐段 TTS 朗读，语速/音色可调，当前段落高亮跟随滚动
- ⏬ **自动滚动（B6）**：可调速度的匀速滚动，触底自动停止
- 🖼 **图片悬停预览（C5）**：正文大图悬停居中放大；夜间模式可自动调暗图片

### 🧹 页面净化
- 广告/直播/课程/带货/咨询卡片/会员推广全量屏蔽
- **按页面分类屏蔽（B2）**：首页/关注/热榜/搜索分别屏蔽视频、文章、想法、盐选、关注动态
- 低赞内容屏蔽（阈值可调）、**低评论内容屏蔽（C3）**
- **搜索页净化（C4）**：隐藏搜索侧边推荐
- 关键词/作者黑名单，**划词快捷加屏蔽词（A3）**
- 折叠低质短评与广告评论

### ⚡ 效率增强
- 站外直链还原、完整时间显示、代码块一键复制
- **默认收起长回答（C1）**、一键收起全部
- **显示提问者（C2）**、回答链接旁"直达问题"按钮
- **信息流新标签页打开（B7）**
- **回答聚合侧栏（A1）**：问题页按赞排序速览全部回答，点击定位
- 🗂 **本地收藏夹（B4）**：收藏回答/好表达，支持导出 Markdown
- 可自定义键盘快捷键（C7）：Alt+字母，8 个动作随意绑定

### 🤖 智能增强
- **AI 总结（B1）**：自备 API Key（DeepSeek / 通义千问 / OpenAI / 任意兼容接口），SSE 流式总结回答
- **一句话提炼（B3）**：自动提炼核心观点 + 内容类型标签（疑似软文/情绪表达/知识/观点）

### 📊 统计与健康
- **阅读统计（B5）**：今日/近 7 天时长、字数、篇数
- **时长提醒（B8）**：连续阅读过久自动提醒休息

### ⚙️ 设置体验
- **设置搜索（A4）**：popup 内搜索任意设置项，点击直达
- **本页生效功能面板（C9）**：一眼看清当前页面哪些功能在生效
- 打印优化（C10）：打印时自动隐藏界面元素、正文占满页宽

## 安装（开发者模式）

1. 下载/克隆本仓库
2. 打开 `chrome://extensions/`，开启右上角「开发者模式」
3. 「加载已解压的扩展程序」→ 选择项目根目录

## 油猴轻量版

无法安装扩展时可用 [`zhihu-member-plus-lite.user.js`](./zhihu-member-plus-lite.user.js)（Tampermonkey 安装）。
与扩展保持同版本号，包含净化/过滤/增强/阅读器/快捷键核心功能（AI 总结、TTS、统计等扩展专属功能除外）。

## AI 总结配置

在扩展 popup →「智能」页填入你自己的 API Key。请求从页面直接发往服务商接口（DeepSeek / 阿里云 DashScope / OpenAI 均支持浏览器跨域），Key 与总结内容不经过任何第三方。

## 开发

```bash
node scripts/check.js   # 语法 + manifest + 版本对齐检查
npx eslint@8.57.0 .      # lint
```
